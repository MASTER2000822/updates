note=Purge now finishes. The GameLoop service was never stopped - a service cannot be killed, and it holds its own files - so the folder survived the delete. The services are stopped first, and ONE GameLoop and the new GameLoop (TAC) are removed too, which the original batch never knew.

GameLoop's Add/Remove Programs entry is called just "GameLoop" or the Chinese name, so a purge left it behind and the launcher offered a program that was gone. A GameLoop row is built only when its files exist, and Purge removes those entries too.
note=Purge stops saying it failed when it worked. The batch it runs deletes itself near the end - it empties %TEMP% - so Windows reported an error after a clean purge. The result is now read from the machine: no GameLoop folder left and no Tencent key left means it worked.
note=Purge is the original tool's again, command for command: every drive, every folder, every service and every registry key that batch knew, run the same way. On top of it a sweep now walks the registry and removes anything left that names Tencent - key, value or uninstall entry.

note=That half-install check found a bug in the search rather than in the install. A folder holding nothing but AppMarket still counts as a folder, and the tool used to take the first one it found - so a leftover classic install, whose registry key outlives its files, was described while the real one was never looked at. It now scores every place a GameLoop has ever been and answers with the one that looks like a GameLoop: an engine is worth more than a folder name, and a market on its own is worth almost nothing. The per-user folder the newer downloader uses is on that list too.
