On the way in this build looks in its own folder and the Desktop, Downloads and Documents folders for a copy of the old LamborGini Tool, checks its version, and removes it - a newer copy waiting its turn and this running exe are left alone, and the tool says where it cleaned.
note=Purge now finishes. The GameLoop service was never stopped - a service cannot be killed, and it holds its own files - so the folder survived the delete. The services are stopped first, and ONE GameLoop and the new GameLoop (TAC) are removed too, which the original batch never knew.
note=The engine no longer lists an emulator that is not there. GameLoop's Add/Remove Programs entry is called just "GameLoop" or the Chinese name, so a purge left it behind and the launcher offered a program that was gone. A GameLoop row is built only when its files exist, and Purge removes those entries too.
note=Purge stops saying it failed when it worked. The batch it runs deletes itself near the end - it empties %TEMP% - so Windows reported an error after a clean purge. The result is now read from the machine: no GameLoop folder left and no Tencent key left means it worked.
note=Purge is the original tool's again, command for command: every drive, every folder, every service and every registry key that batch knew, run the same way. On top of it a sweep now walks the registry and removes anything left that names Tencent - key, value or uninstall entry.
note=The four GameLoop installers download from the tool now. The library's English and Chinese cards, 32- and 64-bit, fetch Tencent's own installer from this tool's update channel and check it against its published SHA-256 and size before it runs, instead of sending you to a web page.
note=The line under the repair cards is a bar now. It was a one-pixel rule, and at a scaled window a hairline reads as a row of dots; it is the preparation screen's bar instead - gold, with a highlight travelling along it - and the tools that count in steps still show one tick per step.
note=The link on the empty page sits in its card. "Install an app with Setup" was drawn below the last line with no room reserved for it, so the card's bottom edge cut through the words; it has its own row now, centred, with the same margin above and below it as the rest of the card.
note=A half-installed GameLoop is recognised now. The installer downloads the app market first and the emulator afterwards, so a dropped connection leaves GameLoop opening on its market with no engine behind it - and this tool called that "not installed" to people who had just installed it. Pre-Ready names the missing half and its button opens GameLoop to finish the download; the Library's empty page says the same thing.
note=And that page now says how to finish it. The emulator comes down with the first game installed from GameLoop's market, which is what the card tells you to do - it used to say "open it once and let it finish", and opening the market finishes nothing. If the installer is still on the disk its button runs it again, and the card rescans every few seconds, so it turns itself back into a working page the moment the engine arrives.
