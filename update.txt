GameLoop's Add/Remove Programs entry is called just "GameLoop" or the Chinese name, so a purge left it behind and the launcher offered a program that was gone. A GameLoop row is built only when its files exist, and Purge removes those entries too.

note=Purge is the original tool's again, command for command: every drive, every folder, every service and every registry key that batch knew, run the same way. On top of it a sweep now walks the registry and removes anything left that names Tencent - key, value or uninstall entry.

The per-user folder the newer downloader uses is on that list too.
