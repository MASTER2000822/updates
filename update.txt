note=The full-screen takeover sits in the window now. The flat grey band down the right edge and along the bottom is gone: the screen was being clipped 22 pixels short on those two sides.
note=The picture had square corners where the window is a card with rounded ones. It follows the frame's own corners now - all four edges and all four arcs match the window itself, pixel for pixel.
note=And it arrives cleanly. Fading the still frame and the emblem cut out of it at the same time drew the crop twice, so a bright rectangle sat around the emblem and the page showed through the whole screen. Only a flat veil fades now, and the picture is either absent or opaque.
note=Optimise's screen, the 4K wallpaper and the retired-build card are unchanged.
note=An old 1.2.0 tool left on the machine is retired now. On the way in this build looks in its own folder and the Desktop, Downloads and Documents folders for a copy of the old LamborGini Tool, checks its version, and removes it - a newer copy waiting its turn and this running exe are left alone, and the tool says where it cleaned.
note=Purge now finishes. The GameLoop service was never stopped - a service cannot be killed, and it holds its own files - so the folder survived the delete. The services are stopped first, and ONE GameLoop and the new GameLoop (TAC) are removed too, which the original batch never knew.
note=The engine no longer lists an emulator that is not there. GameLoop's Add/Remove Programs entry is called just "GameLoop" or the Chinese name, so a purge left it behind and the launcher offered a program that was gone. A GameLoop row is built only when its files exist, and Purge removes those entries too.
note=Purge stops saying it failed when it worked. The batch it runs deletes itself near the end - it empties %TEMP% - so Windows reported an error after a clean purge. The result is now read from the machine: no GameLoop folder left and no Tencent key left means it worked.
note=Purge is the original tool's again, command for command: every drive, every folder, every service and every registry key that batch knew, run the same way. On top of it a sweep now walks the registry and removes anything left that names Tencent - key, value or uninstall entry.
note=The four GameLoop installers download from the tool now. The library's English and Chinese cards, 32- and 64-bit, fetch Tencent's own installer from this tool's update channel and check it against its published SHA-256 and size before it runs, instead of sending you to a web page.
note=The line under the repair cards is a bar now. It was a one-pixel rule, and at a scaled window a hairline reads as a row of dots; it is the preparation screen's bar instead - gold, with a highlight travelling along it - and the tools that count in steps still show one tick per step.
note=The link on the empty page sits in its card. "Install an app with Setup" was drawn below the last line with no room reserved for it, so the card's bottom edge cut through the words; it has its own row now, centred, with the same margin above and below it as the rest of the card.
note=A half-installed GameLoop is recognised now. The installer downloads the app market first and the emulator afterwards, so a dropped connection leaves GameLoop opening on its market with no engine behind it - and this tool called that "not installed" to people who had just installed it. Pre-Ready names the missing half and its button opens GameLoop to finish the download; the Library's empty page says the same thing.
note=And that page now says how to finish it. The emulator comes down with the first game installed from GameLoop's market, which is what the card tells you to do - it used to say "open it once and let it finish", and opening the market finishes nothing. If the installer is still on the disk its button runs it again, and the card rescans every few seconds, so it turns itself back into a working page the moment the engine arrives.
note=The Chinese GameLoop is finished by its installer, not by its market. Its market downloads the app you press Install on and nothing else - the emulator never comes that way - so the card no longer tells Chinese users to install something. Its button fetches Tencent's Chinese installer from this tool's channel, checks it, and runs it. The English edition keeps the market route and now names the app that works there.
note=That card stopped guessing. It said the installer had stopped after the app market, and on a customer's machine the installer had plainly finished - it ends on its own Start screen. It now says only what it can see, shows the folder the install was found in, and points at the step that actually pulls the engine down: open GameLoop, sign in, and install a game.
note=And it says how big that step is. The engine is not a patch: a complete GameLoop is about twenty gigabytes, and it arrives while the first game downloads. The card now says so, so nobody watches an empty market for two minutes and gives up. The same check writes what is really inside that folder to %LOCALAPPDATA%\\LamborGini\\gameloop-state.txt, which is what we ask for when a machine still disagrees.
note=That file has now done its job, and it found a bug in the search rather than in the install. A folder holding nothing but AppMarket still counts as a folder, and the tool used to take the first one it found - so a leftover classic install, whose registry key outlives its files, was described while the real one was never looked at. It now scores every place a GameLoop has ever been and answers with the one that looks like a GameLoop: an engine is worth more than a folder name, and a market on its own is worth almost nothing. The per-user folder the newer downloader uses is on that list too.
note=Two words changed with it, because both were promising something the file cannot do. The 3.6 MB Tencent file is called a downloader on its card instead of an installer, and its details say plainly that it puts a market on the disk and stops. An install with only a market in it is titled "Only GameLoop's market is installed", and its button says OPEN THE MARKET - pressing OPEN GAMELOOP and getting AppMarket is a bug even when the code is doing what it was told.
