note=The Cleaning page no longer says it is not running as administrator when it is. That banner was drawn from a flag that is only set at the end of a scan, so on every fresh launch it showed the default value of a bool - over five categories all still marked not scanned, which is the one state it can never be true in, because the build has asked for administrator in its manifest since 3.0.48. If you saw it, nothing was being skipped: the tool was elevated the whole time and the warning was simply wrong.
note=The Network tab's RIGHTS row is fixed by the same change. It read Standard user until something had been scanned, and now reads Administrator from the moment the tool opens. Elevation cannot change while a process is alive, so it is read once at startup instead of being inferred from whether a job had run yet.
note=Preferences now appears in Device whenever anything of GameLoop is left on the machine, not only when the emulator is installed. The page used to be gated on a scan that can only see an emulator it can still launch, which is exactly backwards for a repair page: when GameLoop is half-uninstalled - its services still registered, its keys still in the registry, a TxGameAssistant folder still on D: - the scan found nothing and the page hid the one plate that could have cleaned it up. A trace of either engine, classic or the new Android 13 one, is now enough, and the other four tabs still need a real install.
note=Close Emulator stops the Tensafe driver as well. It had been leaving it running while ending tensafe_1.exe and tensafe_2.exe by name, and a kill cannot hold while the service that starts those two is still up - which is why they were back a minute after a close that had counted them as closed.
note=Close Emulator also waits out a service that restarts itself. Windows applies a service's recovery action when its process dies rather than when it is stopped, and the close ends QMEmulatorService.exe by name, so a close that raced its own stop could leave a service that reappeared a few seconds later with the card already saying closed. It now re-checks for about two seconds and stops it again, and a service still up after that is named in the card instead of being counted as closed.
note=Purge emulator really stops the services before deleting them. It was waiting eight seconds for each one to stop without ever asking it to, and DeleteService only marks a service for deletion - so a running service kept running, kept its folder locked, and the log said removed.
note=Purge emulator removes the desktop and Start menu shortcuts again. The shortcut reader used COM on a worker thread that had never initialised it, so every target read as empty and the log said zero removed over a desktop full of them.
note=The re-scan arrow on the launch card is only the arrow now. It used to sit in a small grey glass key - a shadow, a rim, a lit top edge and a dark floor at a quarter of the size of the buttons below it - which at 26 pixels read as a box with an arrow lost inside it. Pressing it now turns the arrow a full circle and closes its gap into a ring before the scan starts, instead of swapping the card between two frames.
note=The Executables page no longer comes up blank when winget cannot be read.
